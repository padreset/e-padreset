Privacy Policy for E-Pad Reset

Last updated: October 3, 2026

E-Pad Reset is an unofficial utility for compatible Epson printers connected through USB OTG. This app is designed to run locally on your Android device and communicate directly with the connected printer.

Information We Collect

E-Pad Reset does not collect, sell, or share personal data for analytics, advertising, or profiling.

The app may temporarily access the following information only for its core functionality:

  • USB device information required to detect and connect to a compatible Epson printer
  • Printer information returned by the connected device, such as model name, device identifier, status, ink levels, and waste counter values
  • Protocol logs generated locally on your device for debugging and troubleshooting

How Information Is Used

The information accessed by the app is used only to:

  • Detect and connect to a supported USB printer
  • Read printer status and maintenance information
  • Send printer maintenance commands requested by the user
  • Display protocol and diagnostic information inside the app

Data Sharing

E-Pad Reset has no INTERNET permission and does not make network requests or automatically send diagnostic data. Printer communication takes place directly between your Android device and the connected printer over USB.

For an unsupported model you may review and edit a limited report locally. It contains only model-related IEEE1284 fields (MFG, MDL, CMD, CLS), USB vendor/product IDs, app and Android versions, and a summary of the catalog failure. Raw protocol logs, serial-number fields and EEPROM backups are not attached. Review any information you add; automatic filtering cannot judge your additions.

Copying places your chosen draft on the system clipboard. Sharing hands it to the application and recipient you choose, which may use the network under its own privacy policy. Opening Discord or GitHub uses an external app or browser, requires their accounts, and does not publish or paste the report automatically. The GitHub link selects a template without report data in its URL. Requests you post may be visible publicly or to the community. There is no dedicated intake inbox configured; choosing a share target does not guarantee delivery to a maintainer.

Data Storage

The app does not require user account registration and does not maintain a remote user database. Protocol logs are kept locally for troubleshooting. The model report draft is held in memory for review, not sent automatically. Pre-write EEPROM backups are kept in private app preferences (up to five distinct records) to allow restoration; they are never attached to model requests.

Permissions

The app requests USB permission from Android only when needed to communicate with a connected printer. This permission is used exclusively for printer access. Preparing, copying and sharing a model report or opening an external link does not add an INTERNET permission to this app. The source manifest declares no uses-permission entries; the merged manifest additionally declares com.padreset.epadreset.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION, injected by AndroidX Core (androidx.core:core) so the USB-detach receiver can be registered as not-exported. It is a signature-level permission on this app's own package — never shown to the user and never requested from them — and it grants no network, storage or device access.

Third-Party Links

The app may include links to the project repository or related resources. If you open an external link, you will leave the app and be subject to the privacy practices of the destination site.

Children's Privacy

This app is not directed to children and does not knowingly collect personal information from children.

Changes to This Policy

This policy may be updated from time to time. Any updated version will be published on this page.
